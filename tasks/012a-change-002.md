# TASK-012A Change 002 — 후속 품질 부적합 근거와 재검사 연계

## 승인된 변경

- LQC·OQC·고객검수·FAT 부적합 최종화는 사진 1장 이상 또는 30자 이상의 구체 사유를 요구한다.
- 양식 항목 자체가 사진 필수이면 긴 사유로 대체하지 못한다.
- 검사 연계 Pending 조치 완료 시 다음 검사 회차·성적서·업무·정/부 알림을 원자 생성한다.
- 재검사 부적합은 같은 Pending을 다시 열고, 합격만 품질 단계와 Pending을 종결한다.

## 경계

- 실제 검사 양식 content와 PDF layout은 변경하지 않는다.
- 실제 외부 알림 provider 호출은 포함하지 않는다.
