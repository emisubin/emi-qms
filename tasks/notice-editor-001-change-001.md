# TASK-NOTICE-EDITOR-001 Change 001 — 첨부 관리 진입 조건

> 승인일: 2026-08-11
> 승인 source: 사용자 직접 수정 요청
> 상태: 구현·자동 검증 완료 / 사용자 검수 대기

## 사용자 요청

- 공지 상세를 열었을 때는 첨부파일 조회·다운로드만 제공한다.
- 파일 추가와 제거는 작성자가 `공지 수정`을 눌러 편집 화면에 들어간 경우에만 표시한다.

## 확인된 원인과 변경 경계

- 최초 구현은 작성자 상세 화면에 첨부 추가·제거 control을 항상 노출해, 제목·본문 수정과 첨부 편집의 진입 방식이 달랐다.
- Frontend 표시 조건만 조정한다. 작성자만 첨부를 변경할 수 있는 Backend 권한, 다운로드 권한, 파일 검증·보관 정책과 API는 변경하지 않는다.
- 새 공지 작성 중 최초 첨부 선택은 유지한다. 등록 뒤 첨부를 추가·제거할 때만 편집 화면을 사용한다.

## 완료 기준

- 작성자 상세: 첨부 목록·다운로드와 `공지 수정`만 보이고 추가·제거 control은 보이지 않는다.
- 작성자 편집: 제목·본문과 함께 기존 첨부 다운로드·제거, 새 파일 추가가 보인다.
- 다른 조회자: 상세에서 다운로드만 가능하고 편집·추가·제거 control은 없다.
- desktop·390px에서 편집 화면의 horizontal overflow가 없다.
