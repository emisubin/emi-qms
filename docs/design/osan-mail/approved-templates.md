## 함께 제시한 적용 기준

- 사진은 메일에 첨부하지 않고 PMS에서 확인한다.
- 단계 알림 버튼은 해당 프로젝트·패널·단계로 연결한다.
- 동일 일괄 완료/수정 작업의 같은 프로젝트·단계 대상은 메일 한 통으로 묶는다. 제목은 `패널 01 외 4개`처럼 표시하고 본문에 전체 대상을 표시한다. 서로 다른 작업까지 시간 기준으로 합치는 정책은 아니다.
- 시각은 한국 시간으로 표시한다.
- 초기화 메일은 발송하지 않는다. 프로젝트 완료 메일은 최초 완료 시 한 번만 발송한다.
- 반려는 해당 단계에 데이터를 등록한 모든 담당자에게 발송한다. 나머지 업무 메일은 오산 소속 사용자·오산 관리자와 개발 기간 총괄 관리자에게 발송하며 중복 수신자를 제거한다.
- 운영 메일에는 테스트 표시·예시값·PMS 홈으로 연결한 테스트 버튼을 적용하지 않는다.
