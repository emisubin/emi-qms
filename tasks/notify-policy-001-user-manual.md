# TASK-NOTIFY-POLICY-001 — 사용자 알림 안내

## 어떤 알림이 오는가

- 새 프로젝트가 만들어지면 모든 활성 사용자가 인앱·Teams·메일로 받습니다.
- 프로젝트 납기나 상태가 바뀌면 영업담당자와 프로젝트에 지정된 담당자가 인앱·Teams로 받습니다.
- 모든 패널 납품이 끝나는 17단계에는 같은 프로젝트 담당자들이 인앱·Teams로 받습니다.
- 18단계 영업 최종 완료는 영업팀 전체에게 메일만 갑니다.
- 일반 업무가 새로 배정되면 담당자가 인앱·Teams로 받습니다.
- Pending 등록·재검사·재조치는 인앱·Teams·메일로 모두 오며 끌 수 없습니다.
- Pending이 종결되면 처음 등록 알림을 받았던 사용자에게 인앱·Teams로 알려줍니다.
- PWA 기기 푸시는 내가 실제로 볼 수 있는 인앱 알림과 동일하게 옵니다.

## 내가 바꿀 수 있는 설정

`내 알림 설정`에서 다음 3가지만 켜거나 끌 수 있습니다.

- 자동 단계 업무 생성 Teams 알림
- 예정일 직전 영업일 D-1 Teams 알림
- 평일 일일 업무 요약 메일

긴급·차단과 예정일 초과 L1을 포함한 필수 알림은 끌 수 없습니다. 인앱 알림도 항상 기록됩니다.

## 담당자가 없는 업무

프로젝트에 정·부담당자가 없으면 해당 부서의 부서장 전원에게 `부서장 공유` 업무가 표시됩니다. 한 명이 처리하면 다른 부서장 화면에는 `다른 부서장이 처리`로 자동 종료됩니다. 같은 업무를 두 명이 중복 완료할 수 없습니다.

부서장도 한 명도 없으면 시스템이 관리자나 영업에게 임의 배정하지 않고 어떤 부서장을 지정해야 하는지 안내합니다.

## 예정일 알림

- D-1: 예정일 직전 영업일에 현재 담당자에게 Teams 알림이 옵니다.
- L1: 예정일 다음 날 첫 확인 시 현재 담당자에게 Teams와 메일이 옵니다.
- 생산계획 종료일이나 구매품 입고예정일이 바뀌면 아직 끝나지 않은 관련 업무의 예정일도 바뀝니다.
- 정확히 연결되는 일정이 없는 업무는 임의로 프로젝트 납기일을 사용하지 않으며 예정일 알림도 만들지 않습니다.

## 여러 기기에서 받기

휴대폰과 태블릿 등 여러 기기에서 로그인하고 각 기기의 푸시를 켜면 모든 활성 기기에 알림이 옵니다. 분실한 기기가 있으면 `내 알림 설정`에서 `모든 기기 연결 해제`를 사용한 뒤 안전한 기기에서 다시 켜세요. Microsoft 365 로그인 세션 해제는 회사 보안 절차를 별도로 따릅니다.
