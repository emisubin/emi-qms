## 자동 검증 완료

- [x] 조치·품질 외 업무 부서 사용자가 열린 Pending에 코멘트를 등록할 수 있다.
- [x] 같은 사용자는 상태 전이·담당 변경·품질 판정 권한을 새로 얻지 않는다.
- [x] 조회 전용 사용자는 코멘트 form이 보이지 않고 API도 403이다.
- [x] 최초 LQC·OQC 부적합 성적서는 전체 원검사 항목을 유지한다.
- [x] 조치 완료 뒤 재검사는 직전 부적합 항목만 표시하고 이전 근거를 보여준다.
- [x] 재검사 대상 밖 응답 저장은 400으로 거절된다.
- [x] 재검사 부적합은 같은 Pending을 재조치로 되돌리고, 다시 조치한 뒤 같은 실패 항목만 재검사할 수 있다.
- [x] 재검사 합격은 같은 Pending을 종결한다.
- [x] 제조 실행 뒤 LQC 누락 패널은 검사함에 한 번만 복구되고 반복 재조정은 중복을 만들지 않는다.
- [x] 지정 프로젝트 2번 패널은 LQC 검사함에 표시되고 OQC는 LQC 합격 전까지 열리지 않는다.

## 사용자 수동 검수

- [ ] 영업·설계·생산관리·구매·자재·물류 중 한 사용자로 열린 Pending 상세에 들어가 코멘트를 등록한다.
- [ ] 코멘트가 하단 `코멘트와 처리 이력`에 바로 나타나는지 확인한다.
- [ ] 같은 사용자가 조치 시작·완료나 품질 재검사 판정을 할 수 없다는 기존 권한 경계를 확인한다.
- [ ] 조회 전용 사용자로 같은 Pending을 열었을 때 코멘트 입력창이 보이지 않는지 확인한다.
- [ ] LQC 또는 OQC에서 여러 항목 중 한 항목만 부적합 처리한다.
- [ ] 조치 담당자가 조치 완료한 뒤 품질 재검사 화면에 부적합 항목 하나와 `이전 부적합 근거`만 보이는지 확인한다.
- [ ] 재검사에서 다시 부적합 처리하면 기존 Pending이 재조치 상태로 돌아가고, 다시 조치 완료 뒤 같은 실패 항목만 열리는지 확인한다.
- [ ] 재검사에서 적합 처리하면 Pending이 종결되는지 확인한다.
- [ ] 지정 프로젝트의 2번 패널이 LQC 검사함에 있고 OQC에는 아직 없는지 확인한다.
- [ ] 2번 패널 LQC를 합격 완료한 뒤에만 OQC가 열리는지 확인한다.
- [ ] Desktop과 Mobile에서 이전 부적합 근거와 판정 버튼이 잘리지 않는지 확인한다.
