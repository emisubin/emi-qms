- Frontend: `http://127.0.0.1:42983`
- Backend: `http://127.0.0.1:41166`

검수 계정: 설계 담당자

## 자동 검증 완료

- [x] 신규 UL891 프로젝트 상세 설계 탭에 입력창이 표시되지 않는다.
- [x] UL891 상세에서 일반 `패널명·사이즈 수정` 영역이 중복 표시되지 않는다.
- [x] 저장된 세트 공통 패널명·규격·치수와 실물 세트·개별 패널을 조회할 수 있다.
- [x] 패널 QR 목록과 일괄 관리 기능이 유지된다.
- [x] `수정` 버튼은 별도 UL891 설계 입력 화면으로 이동한다.
- [x] 입력 화면에 `임시저장`과 `저장`이 표시되고 기존 `Draft 저장`·`사양 확정`은 표시되지 않는다.
- [x] 임시저장·저장의 진행·성공·실패 안내가 해당 세트 action 가까이에 표시된다.
- [x] 비-UL891 프로젝트는 기존 평면 패널 수정·Excel 입력 경로를 유지한다.
- [x] Desktop과 390px에서 horizontal overflow가 없고 browser warning/error가 없다.

## 사용자 수동 검수

- [ ] UL891 프로젝트의 `설계` 탭에 설계 입력창이 없이 조회 내용만 보이는지 확인한다.
- [ ] 세트 사양 아래에 같은 패널명·치수를 다시 입력하는 일반 설계 영역이 없는지 확인한다.
- [ ] `패널 QR` 영역이 그대로 보이는지 확인한다.
- [ ] `수정`을 눌렀을 때 별도 입력 화면으로 이동하는지 확인한다.
- [ ] 일부 값을 바꾸고 `임시저장`했을 때 성공 안내가 바로 보이며 다시 수정할 수 있는지 확인한다.
- [ ] 최종 `저장`했을 때 성공 안내와 `저장 완료` 상태가 보이는지 확인한다.
- [ ] 설계 탭으로 돌아왔을 때 저장한 값이 조회되는지 확인한다.
- [ ] 일반 프로젝트의 기존 설계 수정 화면이 그대로 동작하는지 확인한다.
