# 외함 IQC 운영 절차서

적용 대상: `CategoryBased` 정책으로 생성된 신규 프로젝트

## 1. 구매품 구분 관리

1. 품질팀 사용자가 `양식 관리 → 구매품 구분·IQC 연결`을 연다.
2. 구분 이름과 `IQC 필요/없음`을 확인한다.
3. 신규 구분이 필요하면 추가하고 IQC 여부를 정한 뒤 저장한다.
4. 더 이상 쓰지 않는 구분은 삭제하지 않고 사용 중지한다.
5. 이미 구매품에 선택된 구분은 이후 catalog 설정을 바꿔도 과거 판단이 바뀌지 않는다.

초기 운영 기준:

| 구분 | IQC |
| --- | --- |
| 외함 | 필요 |
| 판금류 | 없음 |
| 부스바 | 없음 |
| 명판 | 없음 |
| 기타 | 없음 |

## 2. 구매 등록

1. 구매 담당자는 신규 프로젝트의 모든 구매품에 구분을 선택한다.
2. 외함이면 `외함`, 나머지는 실제 분류 또는 `기타`를 선택한다.
3. 직접 입력과 Excel 입력 모두 같은 기준을 사용한다.
4. 도착 등록 뒤에는 해당 구매품 구분을 바꾸지 않는다. 잘못 분류했다면 신규 도착 전에 구매 담당자가 수정한다.

## 3. 자재 도착 등록

- 외함: 도착 등록 즉시 품질팀 외함 IQC 업무가 생성된다. 자재 담당자는 IQC 결과를 기다린다.
- 비외함: 도착 등록 즉시 `검사 대상 아님`과 자재 입고 확정 업무가 생성된다. 자재 담당자가 수량·도착 내용을 확인한 뒤 `입고 확정`을 누른다.
- 도급·사급은 IQC 판단에 영향을 주지 않는다.

## 4. 외함 IQC

1. 협력사 종이 수입검사서와 실제 외함을 확인한다.
2. 종이 검사서에 EMI 확인 내용과 서명을 기입한다.
3. 품질 IQC 업무를 열어 `검사 시작`을 누른다.
4. 서명본을 PDF·JPEG·PNG로 올린다.
5. 결과를 `적합` 또는 `부적합`으로 선택하고 판정 사유를 작성한다.
6. 첨부와 판정을 다시 확인한 뒤 한 번만 확정한다.

확정 후에는 수정할 수 없다. 잘못된 파일이나 판단을 발견하면 기존 기록을 고치지 말고 품질 책임자에게 보고해 별도 운영 조치를 결정한다.

## 5. 부적합과 재검사

1. 부적합 확정 시 기존 Pending 절차에 따라 조치 담당자가 조치를 수행한다.
2. 조치 완료 후 품질팀에 재검사 업무가 생성된다.
3. 품질팀은 이전 부적합 사유·조치 내용·첨부를 확인한다.
4. 재검사한 새 종이 검사서에 확인·서명하고 새 스캔본을 올린다.
5. 적합이면 Pending이 종결되고 자재 입고 확정 업무가 생성된다.
6. 다시 부적합이면 같은 Pending이 다시 조치 요청으로 돌아간다.

이전 검사와 재검사의 파일·판정·조치 내용은 회차별로 모두 보존한다.

## 6. 예외 대응

- 구분을 선택할 수 없음: 품질팀이 양식 관리에서 해당 구분의 사용 상태를 확인한다.
- 잘못된 파일 형식: PDF·JPEG·PNG 원본으로 다시 등록한다. 확장자만 바꾸지 않는다.
- 확정 버튼이 비활성 또는 오류: 스캔본 1개 이상, 판정, 사유와 최신 화면 상태를 확인한 뒤 다시 시도한다.
- 기존 프로젝트에서 구분 입력란이 없음: 정상이다. 해당 프로젝트는 기존 모든 구매품 상세 IQC 절차를 유지한다.
- 확정 기록 수정 요청: 확정본은 감사 근거이므로 수정하지 않는다.
