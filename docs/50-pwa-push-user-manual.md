# EMI PMS PWA 푸시 사용자 안내

## 이 기능은 무엇인가요?

EMI PMS의 인앱 알림을 휴대폰이나 검사용 태블릿 알림으로도 받을 수 있는 기능이다. 같은 계정으로 여러 기기에 로그인해 각 기기에서 푸시를 켜면 모든 허용 기기에 같은 알림이 온다.

## 처음 켜기

1. EMI PMS를 홈 화면에 설치하고 설치된 앱으로 로그인한다.
2. 첫 안내에서 `푸시 알림 켜기`를 누른다.
3. iPhone 또는 Android의 알림 허용 창에서 `허용`을 선택한다.
4. 안내를 닫았거나 다시 설정하려면 `알림 → 내 알림 설정 → 기기 푸시 알림`으로 이동한다.
5. `이 기기 켜기`를 누르고 `이 기기의 푸시 알림이 켜져 있습니다.`를 확인한다.

`나중에`를 누르면 같은 기기에서 안내가 자동으로 다시 뜨지 않는다. 내 알림 설정에서는 언제든 다시 켤 수 있다.

## 끄기와 분실 기기 대응

- 현재 휴대폰·태블릿만 끄기: `내 알림 설정 → 이 기기 끄기`
- 로그인한 모든 기기의 푸시 끄기: `모든 기기 연결 해제`
- 정상 로그아웃: 현재 기기의 푸시 연결도 함께 해제하며 다른 기기는 유지한다.

`모든 기기 연결 해제`는 Microsoft 365 로그인까지 해제하지 않는다. 기기를 분실했다면 회사 계정 보안 절차로 해당 기기의 로그인도 별도로 해제한다.

계정이 비활성화되거나 삭제 예정이 되면 연결된 기기 푸시도 모두 꺼진다. 계정이 다시 활성화돼도 예전 기기 푸시는 자동으로 켜지지 않으므로, 사용할 각 기기에서 다시 `이 기기 켜기`를 눌러야 한다.

## 알림을 눌렀을 때

푸시를 누르면 EMI PMS가 열리고 해당 인앱 알림 상세로 이동한다. 로그인이 만료됐으면 Microsoft 365 로그인을 먼저 거친다. 프로젝트 권한이 없거나 계정이 비활성화됐으면 상세 내용은 표시되지 않는다.

## 알림이 오지 않을 때

1. 홈 화면에 설치한 EMI PMS에서 `내 알림 설정`을 연다.
2. `브라우저에서 알림이 차단되었습니다. 기기 설정에서 EMI PMS 알림을 허용해 주세요.`가 보이면 iPhone/Android 설정에서 EMI PMS 알림을 허용한다. 앱이 기기 설정을 강제로 바꿀 수는 없다.
3. `이 기기에서 알림 권한을 아직 선택하지 않았습니다.` 또는 `이 기기의 알림 권한은 허용되어 있지만 푸시 연결은 꺼져 있습니다.`가 보이면 `이 기기 켜기`를 누른다.
4. 브라우저 상태 확인 오류가 보이면 `다시 시도`를 누른다. 다른 기기 연결이 남아 있으면 현재 브라우저 상태와 관계없이 `모든 기기 연결 해제`를 사용할 수 있다.
5. 여전히 오지 않으면 인앱 알림이 생성됐는지 먼저 확인하고 담당자에게 문의한다.

푸시를 켜지 않아도 인앱 알림과 모든 업무 기능을 사용할 수 있다.
