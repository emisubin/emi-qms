## 사용자 검수

### 1. 양식 관리

- [ ] System Administrator로 `양식 관리`에 들어가 `양식 종류` 안의 연결형 양식 2개를 확인한다.
- [ ] `Item별 제조 양식`에서 Item을 선택하고 제조 항목이 `No. / 제조 항목 / 관리` 행으로 정렬되는지 확인한다.
- [ ] `생산계획·실적 연결`에서 계획 항목 한 줄을 눌러 해당 항목의 source만 펼쳐지는지 확인한다.
- [ ] 현재 양식은 조회 전용으로 시작하고 `수정`을 누르면 입력할 수 있으며 `저장/취소`가 표시되는지 확인한다.
- [ ] “저장 이후 새 프로젝트부터 적용” 안내가 이해하기 쉬운지 확인한다.
- [ ] 제조 항목명을 바꿔 저장했을 때 저장 완료 안내가 나오고 기존 생산계획 연결이 유지되는지 확인한다.
- [ ] 생산계획이 참조하는 제조 항목을 삭제·교체했을 때 제조 저장은 완료되고, 생산계획 화면에서 `연결 재설정 필요`가 크게 표시되는지 확인한다.
- [ ] 끊긴 연결을 현재 제조 단계로 다시 선택해 저장할 수 있는지 확인한다.
- [ ] `OQC 합격`은 선택지 한 건만 보이고 OQC 세부 검사 항목은 실적 연결 목록에 나오지 않는지 확인한다.
- [ ] 생산관리 탭의 `생산계획표` 헤더 글자가 선명하게 보이는지 확인한다.
- [ ] 계획·실적 일정표의 날짜 축을 보고 각 막대의 시작·종료 위치를 바로 해석할 수 있는지 확인한다.

### 2. 신규·기존 프로젝트 경계

- [ ] 기존 프로젝트의 기존 계획 항목과 값은 유지되면서 현재 생산계획표와 계획·실적 2중 막대가 표시되는지 확인한다.
- [ ] 기존 단일 예정일이 같은 날의 시작·종료로 표시되고 저장 후에는 해당 프로젝트 전용 기간으로 바뀌는지 확인한다.
- [ ] 연결 양식이 활성화된 Item으로 새 프로젝트를 생성한다.
- [ ] 새 프로젝트 생산관리 탭에 `연결 실적`을 포함한 9열 생산계획표가 표시되는지 확인한다.
- [ ] 이후 master 양식을 변경해도 방금 생성한 프로젝트 항목·연결이 바뀌지 않는지 확인한다.

### 3. 계획 입력

- [ ] 생산계획 담당자로 `생산계획 수정`을 누른다.
- [ ] 항목마다 계획 시작일·종료일, 연결할 실적 하나, 담당자, 필요 인원과 생산관리 코멘트를 입력하고 저장한다.
- [ ] 저장 후 생산계획표에 담당자·필요 인원·코멘트가 표시되는지 확인한다.
- [ ] 필요 인원에 0 또는 1000을 입력했을 때 구체 오류가 표시되는지 확인한다.
- [ ] 생산계획표와 모바일 카드에 각 항목의 `연결 실적`이 이해 가능한 이름으로 표시되는지 확인한다.
- [ ] 계획 시작일이 종료일보다 늦을 때 이해 가능한 오류가 표시되는지 확인한다.
- [ ] 프로젝트 전용 항목 또는 연결을 수정해도 master 양식과 제조 snapshot이 바뀌지 않는지 확인한다.
- [ ] 계획 항목을 여러 개 추가하고 중간 행을 삭제한 뒤 다시 추가·저장해도 오류가 없고 순번이 1부터 연속인지 확인한다.

### 4. 자동 실적

- [ ] 구매 발주, 자재 입고/IQC, 제조/LQC, OQC·전진검수, 포장·출발·납품을 기존 부서 화면에서 처리한다.
- [ ] 생산관리 탭을 다시 열었을 때 해당 항목 진행률과 실적 시작·종료가 자동 갱신되는지 확인한다.
- [ ] `근거 N건`을 열어 실제 품목·패널별 완료·대기 상태를 추적할 수 있는지 확인한다.
- [ ] 일부 대상만 완료했을 때 100%가 되지 않고 진행 중으로 표시되는지 확인한다.
