# 공지사항 사용자 매뉴얼

## Home에서 확인하기

Home 맨 아래 `공지사항`에는 최신 글 5개가 표시됩니다. 글에는 제목, 한 줄 미리보기, 작성자, 부서와 작성 시각이 나옵니다. 글을 누르면 전체 내용을 볼 수 있습니다.

## 전체 공지 보기

`공지 전체 보기`를 누르면 전체 게시판으로 이동합니다. 최신 글부터 20개씩 표시되며, 제목이나 카드를 누르면 상세 화면이 열립니다.

## 공지 작성하기

1. 게시판에서 `공지 작성`을 누릅니다.
2. 제목과 내용을 입력합니다.
3. `공지 등록`을 누릅니다.

작성자와 부서는 따로 입력하지 않아도 현재 로그인 정보로 자동 저장됩니다. 등록에 실패해도 작성 중인 내용은 사라지지 않습니다.

## 내 공지 삭제하기

내가 작성한 공지 상세에는 `내 공지 삭제` 버튼이 표시됩니다. 확인 창에서 삭제하면 Home과 목록에서 사라집니다. 다른 사용자의 공지는 삭제할 수 없습니다.

잘못 쓴 내용을 고치려면 기존 글을 삭제한 뒤 새 글로 등록해 주세요. 현재 버전은 수정, 첨부, 댓글, 반응 기능을 제공하지 않습니다.

## 모바일

모바일에서도 Home 하단에서 최신 공지를 확인하고, 전체 목록·작성·상세를 같은 순서로 이용할 수 있습니다. 목록은 제목과 핵심 미리보기를 우선 표시하며 좌우 스크롤 없이 구성됩니다.
