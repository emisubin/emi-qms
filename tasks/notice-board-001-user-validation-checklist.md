# TASK-NOTICE-BOARD-001 사용자 검수 체크리스트

- 상태: `사용자 검수 대기 — 마지막 일괄 검수`
- 검수 환경: experiment branch의 승인된 validation runtime
- 주의: 대표 repo·`main`·Persistent UAT·실제 provider에는 반영되지 않았다.

## Home 회귀

- [ ] PC Home 상단 부서 KPI가 변경 전과 동일하게 표시된다.
- [ ] PC Home 중앙 내 업무·Pending·알림이 변경 전과 동일하게 동작한다.
- [ ] 모바일 Home의 우선 확인·내 업무 영역이 변경 전과 동일하게 동작한다.
- [ ] Home 하단의 `프로젝트 병목`만 `공지사항`으로 교체됐다.
- [ ] 프로젝트 목록·상세의 기존 병목 정보는 그대로 조회된다.

## 공지 조회·작성

- [ ] 서로 다른 부서 사용자에게 같은 최신 공지가 보인다.
- [ ] Home에는 최신 공지 5개까지만 제목·미리보기·작성자·부서·시각과 함께 보인다.
- [ ] 전체 게시판에서 최신순 20건 pagination이 동작한다.
- [ ] 제목 없이 등록하면 제목 오류와 focus가 표시된다.
- [ ] 내용 없이 등록하면 내용 오류가 표시된다.
- [ ] 등록 중 반복 클릭해도 같은 공지가 중복 생성되지 않는다.
- [ ] 작성자와 부서가 입력값이 아니라 현재 로그인 사용자로 자동 기록된다.
- [ ] 원문이 HTML로 실행되거나 URL로 자동 링크되지 않고 plain text로 보인다.

## 삭제·권한

- [ ] 작성자 본인 상세에만 `내 공지 삭제`가 보인다.
- [ ] 다른 사용자와 관리자는 타인 공지를 삭제할 수 없다.
- [ ] 삭제한 공지가 Home·목록·상세에서 더 이상 보이지 않는다.
- [ ] 승인 대기·비활성·미인증 사용자는 공지 API에 접근할 수 없다.

## 모바일

- [ ] 390px에서 Home 공지 카드의 제목·미리보기·작성자·부서가 카드 안에 정렬된다.
- [ ] 390px 전체 목록에 가로 스크롤이 없다.
- [ ] 390px 작성·상세 화면의 버튼과 입력칸이 잘리지 않는다.

## 제외 기능 확인

- [ ] 공지 작성으로 내 업무·인앱 unread·Teams·메일이 생성되지 않는다.
- [ ] 수정·첨부·댓글·반응 UI가 노출되지 않는다.
