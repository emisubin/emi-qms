# TASK-HOME-002 사용자 안내 — 개인화 홈과 프로필

## 로그인 사용자 확인

PC에서는 모든 페이지의 오른쪽 위에 프로필 사진, 부서명, 이름이 표시됩니다. 모바일에서는 오른쪽 위 원형 프로필 버튼으로 같은 정보를 확인할 수 있습니다.

## 프로필 사진 변경

1. PC의 오른쪽 위 사용자 정보 또는 모바일의 오른쪽 위 프로필 버튼을 누릅니다.
2. 팝업의 큰 프로필 사진이나 `사진 변경`을 누릅니다.
3. 5MB 이하 JPEG 또는 PNG 파일을 선택합니다.
4. 변경 완료 안내가 나오면 새 사진이 즉시 공통 shell에 반영됩니다.

`사진 제거`를 누르면 기본 이니셜 avatar로 돌아갑니다. 사진이 아직 없으면 제거 버튼은 비활성화됩니다.

## 로그아웃

Microsoft 365 로그인 환경에서는 계정 팝업의 `로그아웃`을 누릅니다. 개발용 Dev 인증은 실제 로그인 세션이 없으므로 로그아웃 버튼이 비활성화될 수 있습니다.

## 부서별 홈

Home 상단의 `부서 핵심 지표`는 현재 사용자 부서에 따라 최대 3개만 표시합니다.

- 관리: 사용자 승인 대기, 알림 실패, 에스컬레이션
- 영업: 담당 진행 프로젝트, 14일 내 납기, 정산 대기
- 설계: 설계정보 미완료 프로젝트·패널, 설계 진행 업무
- 생산관리: 생산계획 미등록·작성 중, 담당 미지정
- 구매: 입고 예정 대기·지연·완료
- 자재: 도착 등록, IQC, 키팅 대기
- 제조: 제조 대기·진행·차단
- 품질: 검사 대기, 재검·조치, 판정 완료
- 물류: 포장·출발·배송 완료 대기

지표 카드를 누르면 관련 업무 화면으로 이동합니다. 권한이 없는 지표나 부서가 없는 사용자는 허용된 기존 Home widget만 사용합니다.

## 모바일 메뉴

왼쪽 위 메뉴 버튼을 누르면 전체 업무 메뉴가 나타납니다. 개발·검수 사용자 전환은 이 drawer의 맨 아래에 있습니다. 오른쪽 위 프로필 버튼은 계정 정보와 사진 변경 전용입니다.
