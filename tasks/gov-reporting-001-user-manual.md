# 결과 보고에서 확인할 것

앞으로는 다음 내용을 짧게 설명한다.

- 실제로 무엇이 바뀌었는지.
- 어떤 검사와 화면 확인을 했고 무엇을 못 했는지.
- 사용자가 확인할 것과 남은 문제가 무엇인지.
- local commit·원격 병합·공개배포 중 어디까지 끝났는지.

자동 테스트 완료가 사용자 검수 완료를 뜻하지 않는다. 품질상 게시 가능이라는 판단도 원격 병합·배포 승인을 대신하지 않는다. 권한 경계는 [Root AGENTS](../AGENTS.md)를 따른다.

이전 10개 항목 보고의 사용자 안내·검수 이력은 [보존본](../docs/archive/harness-v1-2026-09-09/gov-reporting-001-user-manual.md.snapshot)에 있다.
