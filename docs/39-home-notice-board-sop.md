# Home 공지사항 게시판 운영 절차

## 목적

승인 완료된 active 사용자가 부서와 역할에 관계없이 공지를 공유하되, 업무 알림·내 업무·Teams·메일과 혼동하지 않도록 운영한다.

## 작성

1. Home 하단 `공지사항`에서 `공지 전체 보기`를 누른다.
2. `공지 작성`을 누르고 제목 1~100자, 내용 1~2,000자를 입력한다.
3. `공지 등록`을 한 번 누른다. 네트워크 재시도 시 같은 작성 요청은 중복 등록되지 않는다.
4. 작성자 이름·부서·작성 시각은 로그인 정보로 서버가 자동 기록한다.

공지에는 비밀번호, token, 개인 연락처, 고객 비밀이나 민감한 첨부 링크를 입력하지 않는다. v1은 plain text만 지원하며 URL 자동 링크, 파일, 댓글과 수정 기능은 없다.

## 조회

- Home은 삭제되지 않은 최신 공지 5건만 표시한다.
- 전체 게시판은 최신순으로 20건씩 표시한다.
- 목록은 내용의 공백을 한 칸으로 정리한 100자 미리보기만 반환하고, 전체 원문은 상세 화면에서 조회한다.

## 삭제·정정

- 작성자 본인만 `내 공지 삭제`를 사용할 수 있다.
- 삭제는 soft delete이며 일반 목록과 상세에서 숨겨지지만 작성·삭제 이력은 DB에 보존한다.
- v1은 수정 기능이 없다. 잘못 작성한 글은 본인이 삭제한 뒤 새 공지로 다시 등록한다.

## 장애 대응

- 목록·상세 오류: 화면의 `다시 시도`를 사용한다.
- 등록 오류: 입력값은 화면에 유지된다. 오류 문구를 확인하고 같은 작성 화면에서 다시 등록한다.
- 삭제 권한 오류: 현재 로그인 사용자와 작성자를 확인한다. 관리자도 다른 사용자의 글을 삭제할 수 없다.
- 비승인·비활성 계정: 공지 API에 접근할 수 없다. 계정 승인·활성 상태를 먼저 복구한다.

## 운영 경계

공지를 등록해도 notification, work item, unread count, Teams, 메일 delivery는 생성되지 않는다. 이 기능을 긴급 업무 배정이나 Pending 처리 수단으로 사용하지 않는다.
