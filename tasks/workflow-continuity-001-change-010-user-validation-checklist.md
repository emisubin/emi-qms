- [ ] 품질 사용자로 프로젝트 상세 `전체 흐름`을 열어 LQC 완료 패널이 한 면뿐인 경우 LQC가 `부분 완료`인지 확인한다.
- [ ] 생산관리 사용자로 일부 패널만 제조 투입 요청한 뒤 `키팅 완료 (선택)`이 `부분 완료`인지 확인한다.

- [ ] 품질 사용자 `내 업무`와 OQC 검사함에서 자동 복구된 OQC 업무가 한 번만 보이는지 확인한다.
- [ ] Mobile 390px 화면에서 키팅·제조·LQC·제조 완료 상태가 잘리지 않고 읽히는지 확인한다.
