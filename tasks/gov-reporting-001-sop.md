# 작업 결과를 기록하는 방법

현재 절차는 [완료 정책](../docs/12-task-completion-policy.md)을 따른다. Task/change 한 곳에 실제 변경·검증 근거·남은 문제·다음 행동을 기록하고, 대화에서는 사용자가 알아야 할 결과와 한계를 설명한다.

구현·자동 검증·사용자 검수·원격 반영·배포를 구분한다. 내용이 없는 SOP/manual/N/A 섹션이나 고정 보고 제목을 만들지 않는다. 실무에 필요한 반복 운영 절차와 사용자 행동 안내만 해당 자료에 갱신한다.

이전 절차 전문은 [보존본](../docs/archive/harness-v1-2026-09-09/gov-reporting-001-sop.md.snapshot)에 있다. 현행 실행 규칙은 아니다.
