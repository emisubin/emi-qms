# TASK-PRIVACY-NOTICE-001 User manual

## 개인정보·이용 안내 보기

로그인 뒤 각 페이지 맨 아래의 회사 정보 영역으로 내려가 우측 하단의 `개인정보·이용 안내` 텍스트를 누른다. 회사 정보와 같은 글꼴·크기로 표시되며 별도 버튼 외형은 없다. 왼쪽·모바일 메뉴와 계정 메뉴에는 별도 진입 버튼을 두지 않는다.

화면 상단 목차에서 개인정보 처리, 외부 서비스, 문의와 권리, 사내 이용 기준을 누르면 선택 표시를 남기지 않고 해당 내용까지 부드럽게 내려간다. 모션 감소 설정을 사용하면 이동 애니메이션 없이 바로 이동한다. 문의가 필요하면 화면에 표시된 담당 부서와 업무 연락 창구를 사용한다.

화면 상단과 시범 운영 안내에는 별도의 굵은 강조선을 사용하지 않고, 얇은 중립 테두리로만 정보 영역을 구분한다.

desktop 왼쪽 메뉴, mobile 상단과 mobile 전체 메뉴의 EMI PMS logo를 누르면 `홈` 메뉴를 누른 것처럼 업무 홈으로 이동한다.

## 프로필 사진 등록

계정 메뉴에서 `사진 변경`을 누르면 파일 선택 전에 `프로필 사진 선택 동의`가 열린다. 목적·보유 기준과 거부 시 영향이 없다는 내용을 확인한 뒤 선택한다.

- `취소`: 사진을 선택하거나 수집하지 않는다. 기본 이니셜로 모든 업무 기능을 계속 이용한다.
- `동의하고 사진 선택`: 기존 JPEG·PNG 선택과 파일 검증으로 이어진다.
- `사진 제거`: 별도 동의 없이 기존 사진을 제거하고 기본 이니셜로 돌아간다.

## 모바일 앱(PWA) 설치 안내

계정 메뉴에서 `EMI PMS 설치 안내`를 열면 기기별 설치 방법과 이용 안내를 볼 수 있다. 설치 뒤에도 온라인 연결과 Microsoft 365 로그인이 필요하다. 현재 업무 알림은 인앱·Teams Activity·메일로 올 수 있으며, 향후 모바일 푸시가 추가되면 기기로 알림이 갈 수 있다. 현재 모바일 푸시는 준비 중이므로 설치나 이용에 알림 권한이 필요하지 않다.

## 현재 검수본 주의

이 화면은 로컬 시범 운영 검수본이다. 사용자의 채택과 회사 문안 확인 전에는 운영 기준으로 사용하지 않는다.
