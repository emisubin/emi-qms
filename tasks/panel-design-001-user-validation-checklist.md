# TASK-PANEL-DESIGN-001 사용자 검수 체크리스트

- 환경: 로컬 검수 서버
- 자동 검증: 완료
- 사용자 직접 검수: 완료
- 검수 데이터: 운영 데이터가 아닌 테스트 프로젝트 사용

## A. 일반 Item — 설계 입력

- [x] 일반 Item 프로젝트의 `설계 → 패널명·사이즈 수정`에 들어가면 필수 입력값이 바로 보인다.
- [x] 목포장 프로젝트는 `패널명 · W · H · D`, 일반 포장은 `패널명`이 필수로 표시된다.
- [x] 패널명 바로 오른쪽에 `도번` 열과 입력칸이 있다.
- [x] W 옆 `i`에 마우스를 올리거나 focus하면 `포장 업무에 필요한 패널의 최외곽 사이즈를 기재해주세요.`가 보인다.
- [x] 안내와 열반 조작 영역이 기존 흑백 wireframe과 어울리며 왼쪽 강조선·색상 강조 box가 없다.
- [x] 모바일에서도 도번·W/H/D·열반 선택이 겹치거나 화면 밖으로 밀리지 않는다.

## B. 패널 열반

- [x] 패널 2면 이상을 체크하고 `선택 패널 열반`을 누르면 같은 열반 번호가 표시된다.
- [x] 열반 1·2를 만든 뒤 해제하거나 다르게 구성해도 현재 열반 번호가 다시 1부터 이어진다.
- [x] 예를 들어 `300 × 500 × 600`과 `400 × 500 × 600`을 열반하면 저장 전 미리보기에 `700 × 500 × 600`이 표시된다.
- [x] 구성 패널의 W/H/D 하나가 비어 있으면 값을 추정하지 않고 `사이즈 입력 필요`가 표시된다.
- [x] 저장 후 설계 탭에서 열반된 패널들이 하나의 2px 검정 일반 테두리로 보인다.
- [x] 열반 안에서 각 패널의 도번·패널명·개별 W/H/D와 `W 합계 × H 최댓값 × D 최댓값`이 함께 보인다.
- [x] 열반 구성 패널 하나를 선택해 `선택 열반 해제` 후 저장하면 열반 테두리와 합계가 사라진다.

## C. 저장·회귀

- [x] 도번·패널명·사이즈·열반을 한 번 저장한 뒤 다시 편집해도 모두 유지된다.
- [x] 기존 값을 수정하면 기존 방식대로 수정사유가 필요하고, 저장 이력에 `도번`·`패널 열반`이 한글로 보인다.
- [x] Excel 양식의 도번을 입력해 미리보기·적용하면 도번이 저장된다.
- [x] 패널명 중복 허용 확인, QR 가능 여부와 설계 완료 판정은 기존과 같다.
- [x] UL891 프로젝트에는 일반 패널 열반 선택·버튼이 나오지 않고 기존 세트 구조는 그대로다.
