## 사용자 요청

1. 생산관리·자재·품질·물류 메뉴는 먼저 세로 업무 목록만 보여 주고, 선택한 업무의 전용 페이지로 이동한다.
2. 각 업무 페이지는 KPI와 프로젝트 목록을 제공하고 프로젝트를 선택해야 입력 내용을 연다.
3. 제조 메뉴는 KPI·프로젝트 목록으로 시작하고, 선택한 한 프로젝트의 제조 입력만 표시한다.
4. LQC·OQC·전진검수·FAT는 각 업무별 프로젝트 목록에서 한 프로젝트를 연 뒤 검사한다.
5. 제조와 패널 품질검사의 패널 목록은 가로 칩이 아니라 입력 영역 왼쪽의 세로 목록으로 표시한다.
6. Pending은 별도 업무 선택 단계를 제거하고 KPI·프로젝트 목록으로 시작하며, 프로젝트를 연 뒤에는 프로젝트 선택을 반복하지 않고 해당 프로젝트 이슈만 간결하게 표시한다.

## Root finding

- 기존 `DepartmentProjectHub`가 업무 선택과 전체 프로젝트 선택을 한 화면에 결합했다.
- 제조·패널 품질검사 화면은 전체 대기열을 읽은 뒤 첫 프로젝트와 첫 패널을 자동 선택했다.
- 품질과 물류는 입력 화면 안에서도 단계 전환을 허용해 메뉴 선택, 업무 선택, 프로젝트 선택의 경계가 중복됐다.
- Pending은 단일 업무인데도 업무 선택 화면을 거쳤고, 프로젝트를 연 뒤에도 프로젝트 선택 필터가 반복됐다. route가 바뀌어도 기존 목록 state가 재사용돼 다른 프로젝트 이슈가 섞일 수 있었다.
- 이 구조에서는 업무별 KPI가 어느 업무를 대표하는지 불명확하고, 한 프로젝트 입력 중 다른 프로젝트로 의도치 않게 전환할 수 있다.
