# 업데이트 공지 확정 양식

배포 지시 시 공지사항 게시글과 업데이트 팝업을 구분한다. 공지 게시글 제목에는 예정·진행 중 같은 접두어를 붙이지 않는다. 본문에는 일시·대상 항목을 넣지 않고, 아래 형식으로 실제 변경 사항만 쉽고 간결하게 작성한다. 마지막은 반드시 `박수빈 올림`으로 끝낸다. 삭제하기로 한 “완료되면 이 공지에 안내하며, 일정이 변경되면 함께 수정하겠습니다.” 문구는 넣지 않는다.

## 공지사항 게시글

```text
YYYY.MM.DD 업데이트 공지

■ 주요 변경 사항

1. [기능 제목]
[사용자가 무엇을 할 수 있게 되는지 쉬운 말로 설명]

2. [기능 제목]
[변경 설명]

■ 이용 안내

업데이트 중에는 등록·수정·삭제가 제한됩니다. 작성 중인 내용은 시작 전에 저장해 주세요.

박수빈 올림
```

기능 제목은 굵게 표시할 수 있다. 항목 수는 배포 내용에 맞춘다. 일시 항목을 삭제했으므로 “아래 시간 동안”처럼 존재하지 않는 항목을 가리키는 문구도 사용하지 않는다.

## 별도 업데이트 팝업

- 저장 제한 시간·대상과 업데이트 중 저장 제한 안내를 표시한다.
- 공지사항 게시글과 별도이며 서버 저장 제한 상태와 연결된다.
- 업데이트 내용 보기로 해당 공지 본문을 확인할 수 있게 한다. 일반 공지사항 팝업을 동시에 자동 활성화하지 않는다.
- 일반 공지사항 팝업은 관리자가 지정한 게시글을 계정별 한 번 표시하는 기존 기능으로 유지하며 저장 제한과 무관하다.
- 팝업은 긴 공지 전문 대신 위 안내를 표시하고 공지 상세로 연결한다. 완료 후 신규 자동 팝업 청구는 하지 않으며, 완료 배너의 수동 조회는 저장 재개를 안내한다. 로컬 구현·검증 기록은 Task 20-15에 있고 운영 반영 여부와 구분한다.
