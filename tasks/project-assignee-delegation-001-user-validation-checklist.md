## 생산관리 이외 부서장

- [ ] 개발 사용자를 `dev-design`으로 바꾸고 같은 프로젝트에서 `생산계획 수정`을 누른다.

- [ ] 설계 소속 활성 사용자만 선택할 수 있다.
- [ ] 담당자를 저장한 뒤 프로젝트 상세 조회에서 전체 담당자 표시가 갱신된다.
- [ ] `dev-quality`에서는 IQC·LQC·OQC·전진검수/FAT 정·부 담당자만 보인다.
