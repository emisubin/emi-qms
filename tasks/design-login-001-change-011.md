## 변경과 확인

모바일 node `51:18`의 402×852 원본 기준으로 배경, x50/y277의 301×298 카드, x-22/y306 제목, 94×120 Microsoft 원본, x119/y473의 164×33 LOGIN, x138/y511의 126×30 상태 유지 영역을 반영했다. Inter 15/600 LOGIN과 12/500 상태 유지 문구·18.75px 체크박스를 실제 Figma Dev Mode에서 확인했다. 모바일 전용 Microsoft 파일은 내보낸 원본 bytes와 SHA-256이 일치한다.

Inter 4.1 정적 웹폰트 400/500/600/700과 SIL OFL을 [공식 배포본](https://github.com/rsms/inter/releases/tag/v4.1)에서 함께 보관하고 지정 화면의 별도 font-family에만 적용한다. 사이트의 다른 화면 서체를 변경하지 않는다. 기존 로그인·상태 유지·승인·재인증·PWA 동작을 유지하며 작은 폭은 같은 비율로 축소하고 짧은 화면에서는 세로 스크롤로 접근한다.

브라우저의 실제 402×852 viewport에서 카드·버튼·체크박스 좌표와 가로 넘침 없음을 확인했다. 로딩 표시의 기존 스타일 간섭을 찾아 위치를 보정했다. 인증 테스트 25개 및 TypeScript 검사를 통과했다. 실제 회사 계정 로그인·기기 카메라 검수와 배포 검증은 수행하지 않았다.
