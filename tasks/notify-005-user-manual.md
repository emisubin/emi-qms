# TASK-NOTIFY-005 User manual — 알림 받기 설정

## 내 알림 설정 열기

- PC: `알림` 화면의 `알림 설정` 버튼을 누른다.
- 모바일: 왼쪽 위 상태 버튼에서 `앱 상태와 계정`을 열고 `알림 설정`을 누른다.

## 변경 가능한 알림

- 자동 단계 업무 생성 — Teams 개인 알림
- 예정일 임박 D-1 — Teams 개인 알림
- 일일 업무 요약 — 메일

스위치를 `받기` 또는 `끄기`로 선택한 뒤 `설정 저장`을 누른다. `끄기`로 바꿔도 인앱 알림과 내 업무 원본은 사라지지 않는다. 관리자가 직접 보낸 알림·업무 배정·테스트 발송도 계속 전달된다.

## 필수 알림

긴급·차단과 예정일 초과 L1~L3는 `필수`로 표시되며 사용자와 관리자 모두 끌 수 없다. 통합 Teams 채널 공지도 조직 공지로 유지된다.

## 기본값 복원

`기본값 복원`을 누르면 사용자가 끈 선택 알림을 모두 다시 받는 상태로 되돌린다. 이미 기본값이면 version이나 감사 이력을 불필요하게 만들지 않고 “이미 기본 알림 설정입니다”라고 안내한다.

## 다른 곳에서 변경된 경우

본인과 관리자가 동시에 저장하면 먼저 저장한 변경만 성공한다. 충돌 안내가 보이면 현재 선택을 확인하고 `다시 불러오기` 후 저장한다. 시스템이 최신 서버 값을 자동으로 덮어쓰지 않는다.

## 관리자 지원

관리자는 `관리자 → 사용자 관리`의 활성 사용자 행에서 `알림 설정`을 열 수 있다. 대상 사용자 이름을 확인한 뒤 변경 가능 3개 항목만 대리 저장하거나 기본값으로 복원한다. 필수 항목은 관리자도 해제할 수 없다.
