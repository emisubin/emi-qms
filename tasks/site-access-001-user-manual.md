# TASK-SITE-ACCESS-001 — 사이트 접속 이력 사용자 안내

현재 구현·검증 상태와 수집 범위의 기준은 [Implementation report](site-access-001-implementation-report.md)입니다.

## 어디에서 보는가

`관리자 메뉴 → 운영 → 전체 감사 이력`으로 이동합니다. 이 화면은 기존 감사 조회 권한이 있는 관리자만 볼 수 있습니다.

사건 필터에서 `사이트 접속`을 선택하고 조회하면 로그인 기록이나 데이터 변경 기록과 구분해서 볼 수 있습니다.

## 한 행이 뜻하는 것

사이트 접속 한 행은 다음 조건을 모두 만족하는 활동을 한 묶음으로 보여줍니다.

- 같은 사용자
- 같은 브라우저 client
- 이전 페이지 활동 이후 30분 미만

같은 브라우저의 여러 탭은 한 client로 묶입니다. 다른 기기, 다른 브라우저 또는 다른 브라우저 프로필은 별도 행입니다. 정확히 30분 이상 활동이 없었다가 다시 접속하면 새 행이 만들어집니다.

일반 브라우저에서는 Web Locks 또는 IndexedDB를 이용해 여러 탭의 client를 한 값으로 맞춥니다. 브라우저 보안 정책이 localStorage와 IndexedDB를 모두 차단한 경우에는 접속 자체를 누락하지 않기 위해 현재 화면이 열려 있는 동안만 유지되는 임시 client로 기록할 수 있습니다. 이 최종 예외에서는 같은 브라우저의 여러 탭이나 새로고침 뒤 접속이 별도 행으로 보일 수 있습니다.

브라우저의 사이트 저장소를 직접 지우면 같은 브라우저에서도 새 client로 인식되어 다음 접속이 별도 행이 될 수 있습니다.

## 어떤 정보가 보이는가

- 최초 접속과 마지막 활동 시각
- 종료 시각과 접속 상태
- 접속한 메뉴의 최초 방문 순서
- 사용자·부서 snapshot
- 앱 접근 결과
- IP와 브라우저·운영체제 계열

주소 전체, query, 프로젝트·업무 식별자, 클릭과 키 입력 내용은 저장하지 않습니다.

고정 메뉴는 `홈`, `개인정보 처리방침`, `공지사항`, `내 업무`, `Teams 알림`, `프로젝트`, `영업`, `G2 운영`, `양식 관리`, `생산관리`, `구매`, `자재`, `제조`, `품질`, `물류`, `알림`, `알림 설정`, `Pending List`, `관리자`의 19개입니다. 앱 접근 결과는 `허용`, `승인 대기`, `비활성 계정` 중 하나로 표시됩니다.

## 접속 상태 해석

- `최근 활동`: 마지막 페이지 신호 후 아직 30분이 지나지 않았습니다.
- `30분 경과`: 명시적 로그아웃 없이 30분 이상 새 페이지 신호가 없습니다.
- `직접 로그아웃`: 사용자가 앱의 로그아웃을 실행했고 종료 기록까지 저장됐습니다.

브라우저 창을 그냥 닫거나 네트워크가 끊기면 종료 시각이 즉시 생기지 않습니다. 이후 30분이 지나면 `30분 경과`로 표시됩니다.

목록과 상세의 접속 시각은 한국 표준시로 표시됩니다. 기록 범위 안내처럼 `UTC`가 붙은 시각만 협정 세계시 기준입니다.

## 중요한 시간 안내

마지막 활동은 페이지 최초 진입, 새로고침 또는 다른 화면으로 이동할 때 기록된 시각입니다. 사용자가 그 사이 계속 일했는지, 자리를 비웠는지, 실제로 몇 시간 근무했는지는 알 수 없습니다. 따라서 근태·근무시간 증빙으로 사용하면 안 됩니다.

## 상세와 Excel

목록과 모바일 카드에서는 접속 메뉴를 요약해서 보여줍니다. `상세 보기`를 누르면 전체 접속 메뉴 순서, 접속 상태, 앱 접근 결과와 접속 환경을 확인할 수 있습니다.

필요한 행을 선택한 뒤 `선택 Excel 내보내기`를 실행하면 화면과 같은 접속 정보를 받을 수 있습니다. Excel에도 접속 기록 시작 시각과 실제 근무시간이 아니라는 안내가 포함됩니다.

선택 Excel 내보내기 자체도 기존 데이터 내보내기 감사 이력에 남습니다. 접속 원장은 감사 기록이므로 사용자가 수정하거나 삭제하는 기능은 제공하지 않습니다.

## 기록이 보이지 않을 때

- 사건 필터가 `사이트 접속`인지 확인합니다.
- 조회 기간이 접속 기록 시작 시각 이후인지 확인합니다. 이 기능 적용 전 접속은 소급 생성되지 않습니다.
- 최근 접속이라면 `새로고침` 후 다시 확인합니다.
- 계속 보이지 않으면 관리자에게 사용자 역할, 확인 시각과 사용한 브라우저 종류만 전달합니다. 실제 IP·이메일·화면의 원본 개인정보는 채팅에 복사하지 않습니다.
