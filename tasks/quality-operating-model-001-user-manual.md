# 구매품 구분·외함 IQC 사용자 안내서

## 품질팀 — 구매품 구분 설정

`양식 관리`에서 `구매품 구분·IQC 연결`을 선택합니다.

- `IQC 필요`: 도착하면 품질팀 외함 IQC 업무가 생성됩니다.
- `IQC 없음`: 도착하면 IQC를 건너뛰고 자재팀 입고 확정 업무가 생성됩니다.
- `사용 중`: 구매 담당자가 새 구매품에서 선택할 수 있습니다.
- `사용 중지`: 새 구매품에서는 선택할 수 없지만 기존 기록은 그대로 남습니다.

외함 이외의 품목도 나중에 IQC 대상으로 바꾸려면 해당 구분의 `IQC 필요`를 켭니다. 이 변경은 그 뒤 새로 저장하거나 구분을 명시적으로 변경하는 구매품부터 적용됩니다.

## 구매팀 — 구매품 입력

새 프로젝트에서는 각 구매품의 `구분`을 반드시 선택합니다.

1. 품목명과 발주 정보를 입력합니다.
2. `구분`에서 외함·판금류·부스바·명판·기타 중 하나를 선택합니다.
3. 저장합니다.

Excel을 사용할 때도 `구분` 열을 채워야 합니다. 빠졌거나 사용 중지된 구분이면 미리보기에서 해당 행을 고치도록 안내합니다.

## 자재팀 — 도착과 입고 확정

외함을 도착 등록하면 상태가 `IQC 요청`으로 바뀝니다. 품질팀이 적합 판정한 뒤 내 업무의 안내를 보고 `입고 확정`을 누릅니다.

비외함을 도착 등록하면 `검사 대상 아님`으로 표시됩니다. 이것은 `IQC 합격`이 아니라 검사를 하지 않는 품목이라는 뜻입니다. 수량과 도착일을 확인하고 바로 `입고 확정`을 누릅니다.

## 품질팀 — 외함 검사

1. `품질 → IQC`에서 해당 외함 업무로 이동합니다.
2. 협력사 종이 검사서와 실제 외함을 확인하고 종이에 서명합니다.
3. 스캔한 PDF 또는 촬영한 JPEG·PNG를 올립니다.
4. `적합` 또는 `부적합`을 선택합니다.
5. 판단 사유를 적고 확정합니다.

파일은 한 회차에 최대 10개, 각각 10MB까지 올릴 수 있습니다. 적합과 부적합 모두 스캔본이 최소 1개 필요합니다.

확정한 뒤에는 파일을 지우거나 판정을 고칠 수 없습니다.

## 재검사

부적합이면 Pending에서 조치가 진행됩니다. 조치 완료 뒤 새 재검사 업무가 오면:

1. 이전 부적합 근거와 조치 내용을 확인합니다.
2. 재검사 결과를 새 종이 검사서에 기록하고 서명합니다.
3. 새 스캔본을 올립니다.
4. 적합 또는 부적합으로 확정합니다.

이전 회차 파일은 화면의 검사 이력에서 다운로드할 수 있습니다.

## 기존 프로젝트

기능 업데이트 전에 만들어진 프로젝트에는 새 구분 정책이 적용되지 않습니다. 구매 구분이 없어도 되며 모든 도착분은 기존 상세 IQC 방식으로 처리됩니다.
