# EMI 프로젝트 통합관리시스템

청주·오산의 프로젝트와 현장 업무를 관리하는 PMS다. React/TypeScript, .NET 10, PostgreSQL과 Microsoft Entra 인증을 사용한다. 사업부 DB를 분리하면서 기존 서버를 함께 사용할 수 있다.

- 처음 이어서 작업하기: [시작 안내](START_HERE.md)
- 실행·승인 원칙: [AGENTS.md](AGENTS.md)
- 제품 순서·현재 Task 찾기: [Roadmap](docs/00-product-roadmap.md)
- 업무 계약·코드·환경 찾기: [PMS 안내](docs/development/pms-project-guide.md)
- 모델 선택·위임·재개: [Codex 작업 방식](docs/development/codex-model-workflow.md)
- 변경 검증과 완료: [검증표](docs/development/validation-matrix.md), [완료 정책](docs/12-task-completion-policy.md)

이미 개발·배포 이력이 있는 저장소다. 초기 bootstrap이나 저장소 생성·게시를 다시 수행하지 않는다. 현재 checkout·원격 main·실행 서버는 서로 다를 수 있으므로 해당 Task의 근거를 확인한다. 실제 비밀번호·계정·고객 데이터는 문서와 commit에 넣지 않는다.
