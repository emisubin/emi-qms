# <기능의 미결정 사항>

사용자 결과·업무 정책·권한·데이터·외부 영향이 달라지는데 현재 계약으로 결정할 수 없을 때만 사용한다. 요구사항이 충분하면 별도 인터뷰 파일이나 요약 확인을 만들지 않는다.

| 결정이 필요한 내용 | 현재 사실·선택지와 영향 | 권장안 | 사용자 결정·출처 |
| --- | --- | --- | --- |
| 필요한 결정만 작성 |  |  |  |

이미 받은 답·유효한 승인은 의미를 바꾸지 않고 같은 Task의 현재 기록에 반영한다. 필수 질문 수·라운드·확인 횟수를 정하지 않는다. legacy runner metadata는 새 기획의 요구사항이 아니다. [작업 양식](task-template.md)과 [Root](../../AGENTS.md)를 따른다.
