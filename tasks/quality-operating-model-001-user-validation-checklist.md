- [x] 일반 품질팀 사용자도 위 기능을 관리할 수 있다.

## 신규 프로젝트 — 구매 담당자

- [x] 새 프로젝트 구매 입력에서 구분을 선택하지 않으면 이해 가능한 오류가 보인다.
- [x] 외함과 일반 구매품을 각각 저장할 수 있다.
- [x] 구매 Excel 양식과 preview에도 `구분`이 있고 누락·비활성 구분은 해당 행 오류로 표시된다.
- [x] 도착분이 등록된 구매품의 구분을 바꾸려 하면 차단된다.

## 신규 프로젝트 — 자재 담당자

- [x] 외함 도착 등록 뒤 품질 IQC 업무로 넘어간다.
- [x] 비외함 도착 등록 뒤 `검사 대상 아님`으로 표시되고 자재 내 업무에 입고 확정이 들어온다.
- [x] 비외함은 IQC 합격으로 표시되지 않는다.
- [x] 비외함을 입고 확정하면 바로 최종 입고되고, 확정 전에는 취소할 수 있다.

## 신규 프로젝트 — 품질팀

- [x] 외함 IQC 화면은 상세 검사 항목 대신 적합·부적합, 판정 사유, 스캔본 첨부로 구성된다.
- [x] PDF·JPEG·PNG를 여러 개 첨부할 수 있다.
- [x] 첨부 없이 적합 또는 부적합 확정을 누르면 차단된다.
- [x] 확장자만 바꾼 잘못된 파일, 10MB 초과 파일, 회차당 10개 초과는 이해 가능한 오류로 차단된다.
- [x] 확정 뒤 판정과 첨부가 조회 전용으로 바뀐다.
- [x] 부적합 확정 뒤 Pending·관련 업무·알림이 생성된다.
- [x] Pending 조치 완료 뒤 재검사 업무가 오고 새 회차에서 새 스캔본이 필수다.
- [x] 재검사 화면에서 최초 검사와 이전 재검사 회차의 판정·조치 내용·첨부를 모두 조회하고 다운로드할 수 있다.
- [x] 재검사 적합이면 Pending이 종결되고 자재 입고 확정 업무가 생성된다.

## 기존 프로젝트 비회귀

## Change 004 — Item별 LQC 운영 상태·검사 양식 사용자 검수

### 양식 관리·프로젝트 고정

- [x] `양식 관리 > Item별 LQC 검사`에는 전체 스위치 없이 Item 선택과 선택한 Item의 상태 스위치만 보인다.
- [x] 시스템 관리자는 Item별 운영 상태를 바꿀 수 있고, 일반 품질 양식 관리자는 스위치가 비활성화된다.
- [x] Item별 검사 항목을 수정·저장할 수 있으며 다른 Item의 항목은 바뀌지 않는다.
- [x] 상태·양식 변경 안내에 `이후 생성 프로젝트부터 적용`되고 기존 프로젝트에는 영향이 없다고 표시된다.
- [x] 변경 전에 생성한 프로젝트는 이전 운영 상태·양식을 유지하고, 변경 뒤 생성한 프로젝트만 새 상태·양식을 사용한다.

### 제조·품질 흐름

- [x] LQC 운영 중지로 생성된 프로젝트는 LQC 담당자를 지정하지 않아도 제조를 시작할 수 있다.
- [x] 해당 프로젝트의 제조 시작 뒤 새 LQC 업무나 알림이 생기지 않는다.
- [x] 해당 프로젝트의 제조 단계가 모두 완료되면 패널이 OQC 대기열로 바로 넘어간다.
- [x] LQC 합격 기록이나 완료 이력이 자동으로 만들어지지 않는다.
- [x] 기존 LQC 검사 성적서·사진·Pending·재검사 이력은 계속 조회된다.
- [x] LQC 운영 중으로 생성된 프로젝트는 기존처럼 LQC 합격 뒤 OQC로 넘어간다.

### 프로젝트·생산계획

- [x] 운영 중지 프로젝트의 전체 흐름과 현재 단계에 LQC가 나타나지 않는다.
- [x] 운영 중지 프로젝트의 목록·상세 진행률이 LQC를 제외한 단계 수로 계산된다.
- [x] 기존 LQC 연결 생산계획은 제조 단계 완료에 따라 막대가 진행되고 `LQC 운영 중지 · 제조 단계 완료로 대체`라고 표시된다.
- [x] 새 생산계획 실적 연결에서 LQC는 운영 중지로 표시되고 선택·저장할 수 없다.

### 화면·양식 보존

- [x] LQC 화면은 프로젝트별 생성 snapshot에 따라 입력 가능 또는 운영 중지·과거 이력 조회를 명확히 안내한다.
- [x] 운영 중지 프로젝트의 품질 탭은 LQC 대신 OQC 대기를 첫 운영 단계로 보여준다.
- [x] PC와 390px 화면에서 Item 선택·스위치·안내·검사 항목이 겹치거나 잘리지 않는다.

### Change 004 게시 경계

- [x] 2026-08-11 사용자 화면 검수를 완료했고 병합·공개배포를 승인했다. 최신 PR head `CI Gate` 통과 후 병합·운영 교체를 실행한다.

## Change 005 — 구매품 구분별 IQC 방식·양식 사용자 검수

### 양식 관리 — 품질 양식 관리자

- [x] `양식 관리 > 구매품별 IQC 양식`에서 이름·코드로 구매품 구분을 찾고 선택할 수 있다.
- [x] 비활성 구매품 구분도 `비활성` 표시와 함께 조회·설정할 수 있다.
- [x] 구분별로 `검사 없음/검사 운영`과 `스캔형/상세형`을 한 번에 저장할 수 있다.
- [x] 상세 검사 항목이 0개이면 상세형 검사를 켤 수 없고 이유가 바로 표시된다.
- [x] 상세형 검사 항목을 추가·수정·삭제해 현재 양식으로 저장할 수 있다.
- [x] 운영 중인 상세형 양식의 마지막 항목 삭제는 차단된다.
- [x] 설정과 양식을 바꿔도 이미 저장된 구매품과 시작된 검사에는 적용되지 않는다는 안내가 보인다.
- [x] 일반 품질 사용자는 IQC 설정 API에 접근할 수 없고, 지정된 품질 양식 관리자는 접근할 수 있다.

### 구매·자재·품질 흐름

- [x] 새 구매품 구분은 `검사 없음`으로 생성되고 기존 구분 관리에서는 IQC 상태가 조회 전용으로 보인다.
- [x] 검사 없음으로 저장한 구매품은 도착 뒤 IQC 없이 입고 확정으로 이동한다.
- [x] 스캔형으로 저장한 구매품은 기존처럼 서명 검사서 첨부 방식의 IQC로 이동한다.
- [x] 상세형으로 저장한 구매품은 해당 구분의 상세 검사 항목으로 IQC를 수행한다.
- [x] 설정을 바꾸기 전에 저장한 구매품은 저장 당시 검사 여부·방식을 유지한다.
- [x] 상세 성적서를 처음 연 뒤 구분 양식을 바꿔도 열린 성적서의 항목은 바뀌지 않는다.
- [x] 상세형 재검사는 직전 실패 성적서의 항목을 유지하고, 스캔형 재검사는 새 스캔본을 요구한다.
- [x] 기존 `AllReceipts` 프로젝트는 기존 전역 자재 수입검사 양식을 계속 사용한다.

### 화면·게시 경계

- [x] PC에서 기존 양식관리 catalog·selector·editor 구조와 같은 디자인으로 보인다.
- [x] 390px에서 검색·구분 선택·검사 설정·항목 편집이 한 열로 보이고 페이지 가로 스크롤이 없다.
- [x] 2026-08-11 사용자 화면 검수를 완료했고 병합·공개배포를 승인했다. 최신 PR head `CI Gate` 통과 후 병합·운영 교체를 실행한다.
