# TASK-008A Change 002 — 도착·IQC 자동 인계와 자재 하위 탭

## 사용자 검수 실패

- 도착 등록 뒤 IQC 요청을 다시 눌러야 했고, 입고와 키팅 데이터가 섞여 있었다.
- 발주품목별 예정·도착·검사·확정·잔량을 한눈에 보기 어려웠다.

## 승인된 변경

- 도착 저장 transaction에서 IQC attempt, 품질 업무, 정/부 알림과 event를 함께 생성한다.
- 정상 흐름의 별도 `IQC 요청` 버튼을 제거하고 기존 endpoint는 과거 데이터 복구용 멱등 경로로 유지한다.
- 프로젝트 자재 탭을 `입고 관리`와 `키팅 관리` 하위 탭으로 나눈다.
- 입고 화면은 공급구분·업체·예정일·발주/도착/확정/처리중/잔량과 회차별 IQC를 연속 카드로 표시한다.

## 경계

- 입고 확정과 품목 마감의 기존 재검증 기준은 유지한다.
- 운영 데이터 backfill은 포함하지 않는다.
